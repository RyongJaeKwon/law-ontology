# law-ontology

**법령 온톨로지 기반 지식베이스 + RAG 플랫폼**입니다. 폐쇄망 환경에서도 동작하도록 설계합니다.

법제처 Open API의 공개 법령(신탁법, 자본시장법 등)과 해석례를 대상으로 합니다.
- 법령의 구조와 관계(계층, 위임, 준용, 정의, 해석)를 **온톨로지로 설계**하고 그래프 DB에 저장합니다.
- 벡터 검색과 그래프 탐색을 결합한 **하이브리드 RAG**로 근거 조문과 함께 답변합니다.

## 로드맵
| 단계 | 내용 |
|---|---|
| 0 | 기획(PRD) + AI 하네스 구축 |
| 1 | 벡터 RAG MVP + 평가셋 (기준 수치 확보) |
| 2 | 법령 온톨로지 설계 + 그래프 DB + 하이브리드 검색 |
| 3 | Redis(시맨틱 캐시 등) + MCP 서버 |
| 4 | GitHub Actions CI + k3d + ArgoCD |
| 5 | Terraform 기반 AWS 인프라 |
| 6 | 평가 기반 개선 루프 |

> 본 프로젝트는 학습 목적이며, 답변은 법률 자문이 아닙니다.
